# Port 288: от допуска к выстрелу

RotWK 2.01, линейный разбор. RW 0x64D7F4 выделяет 0x8c байт и вызывает RW 0x895D98. После базового конструктора записаны таблицы C64818 (модуль), C64808 (+10, Update) и C647E4 (+20, интерфейс спецсилы). Поэтому оружие по +68 от последнего `this` — то же поле +88 от начала модуля. Отдельный экземпляр снаряжается в конструкторе, не выбирается из обычного WeaponSet. Сверка: DONOR BFME2 0x004929D1, 0x00492A72, 0x00492BEB (`WeaponFireSpecialAbilityUpdate.cpp`).

- Допуск (RW 0x896156, C647E4 +20, вызов из RW 0x897E01): без оружия отказ даже без точки. Нет точки — базовая проверка RW 0x851B6E. С точкой нужен источник; RW 0x6CA2BB → RW 0x6CA03E берёт неотрицательный минимум после вычитания 2.5. Сравнивается квадрат минимума с RW 0x6CA525 (2D расстояние **от края источника**, не от центра). Только IMMOBILE дополнительно отказывает выше квадрата (RW 0x6CA935 − 2.5); равенство на обеих границах допускается. Затем та же базовая проверка. RW 0x6CA701 уже реализована в WeaponState.cpp: дальность при dz = −source.z со вторым множителем масштаба.
- Подготовка RW 0x895E60 отказывает при skip и счётчике 2, иначе база. RW 0x895ECE вызывает базовую распаковку, выставляет условие WhichSpecialWeapon (если не повтор с skip), затем при разрешении проигрывает PreAttackFX оружия. RW 0x896033 после базового выхода снимает условие. RW 0x895C6B передаёт базе упаковку с аргументом 1 независимо от входного.
- Тик RW 0x896370 (C64808 +0): **до** базового RW 0x854DF7, только при состоянии 2, найти цель по ID. Если есть цель, AI и текущий локомотор, повернуть к текущей позиции цели (RW 0x5E6810, обычный ограниченный поворот и запись матрицы). Без любой из предпосылок сразу база. Не новый приказ AI и не мгновенный разворот.
- Эффект RW 0x8961F7: сбросить существующий FiringTracker, затем suppress на орде пропускает оружие. Цель-орда заменяется результатом +110 именно интерфейса орды, если он ненулевой. Только готовое оружие получает ID владельца и стреляет: в объект RW 0x6CF328, иначе принудительно в точку RW 0x6CF3D2 (позиция кастера при нулевой точке или NeedLivingTargets). Сообщение трекеру с hard=1, затем BusyForDuration. Независимо от выстрела — базовый эффект и перезарядка найденного модуля. В порту обе формы доставки уже существуют; вторую обработку наггетов добавлять нельзя.

Матрица не измеряет единый эффект: например, PorterFireExtinguisher меняет скорость горения клеток, не HP; RogashLeap использует ProjectileSelf и боевую часть, AgandaurLightingWeapon — урон по радиусу. Эти случаи нельзя объявлять исправленными по одному лишь факту перезарядки. Сверено по архиву INI 1.9.8.3, включая porterextinguishfire.inc, angmarrogashnew.ini, angagandaur.ini и определения оружия. Условия модели WhichSpecialWeapon — область Port 277.
